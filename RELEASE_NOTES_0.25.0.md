# Horizon 0.25.0: First Horizon

Horizon 0.25.0 adds the complete new-player foundation. First Horizon is a deterministic eight-Turn teaching scenario played as the Foundry against Helix and Varkesh practice commanders on a compact fixed map. It uses the normal Orders, economy, diplomacy, combat, Legacy, and Gate engine while adding saved contextual guidance.

## New-player experience

- Launch First Horizon directly from Learn to Play or the first-run welcome.
- Learn the board, Hidden Legacy, exploration, settlement, development, Technology, Tributes, diplomacy, fleets, and deterministic combat through play.
- Save, resume, hide, or restart tutorial guidance without creating an account.
- Continue into Quick Start, a normal four-Era solo game against three Strategic Director civilizations.
- Receive precise explanations when a selected vessel cannot perform an action.

## Horizon Codex

- Search the complete core-rules archive by rule, system, or glossary term.
- Review Turn structure, Orders, exploration, economy, Habitats, Technology, diplomacy, combat, Legacy, and the Horizon Gate.
- Browse all six civilization profiles in the same Codex.
- Open the relevant rule directly from First Horizon or the in-game Rules control.

## Command briefings

Every resolved Turn now produces a private player briefing with resource, Labor, Legacy, Habitat, Combat Unit, Tribute, and Technology changes plus relevant public events. Network projections expose only the current player's briefing.

## Product clarity and accessibility

- The Core Set is presented as the complete playable release.
- Unreleased expansion concepts are moved into a clearly labeled Future Content archive without release promises.
- Tutorial guidance supports reduced motion, larger text, high contrast, keyboard focus, screen-reader live announcements, phone layouts, tablets, desktop, and Steam Deck-sized displays.
- Allowlisted onboarding events contain only event categories and tutorial step numbers. They never contain Orders, rooms, accounts, or game state.

## Compatibility

Existing local saves and network rooms migrate to game schema 17. First Horizon adds optional scenario, tutorial, and resolution-briefing fields without changing standard four-Era or extended five-Era rules.

Native wrappers, platform authentication, commerce, entitlements, push notifications, public matchmaking, ranked play, and new factions remain outside this release.
