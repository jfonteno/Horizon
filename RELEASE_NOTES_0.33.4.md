# Horizon 0.33.4

## Complete faction-lobby viewport correction

- Removed the generic dialog's vertical centering from the faction lobby overlay. A lobby taller than the application window now starts at the reachable top edge instead of extending above it.
- Made the six-seat radial stage responsive to the available viewport height on desktop and mobile.
- Preserved safe bounds for every seat, faction emblem, label, and Human or Bot control.
- Kept the remainder of the room settings on the lobby's normal scroll surface.

## Compatibility

This patch does not change game rules, room data, saved campaigns, Commander accounts, or Content Pack schemas.
