# Horizon 0.35.2 UI playtest patch

- The main menu now opens a read-only Technology Tree. All five branches and four levels can be inspected without starting a game. In a match, the same tree shows current ownership, research effects, prerequisites, exact costs, shortages, and the next available Technology Order.
- Build, Economy, and Technology use retractable right-side menus. Their edge tabs remain available on the map, and the mobile drawer scrolls independently.
- Build shows each Center slot, including existing Centers, portals, and empty slots. Construction entries have resource, vessel, military, or infrastructure icons and distinct category colors. Faction-specific builds continue to use the same quotes and draft flow.
- Economy exchanges and Homeworld output choices use the established resource icons and colors. Text and controls in all three menus are larger.
- Main-menu entries now have distinct icon and border colors.

The gameplay rules and saved-game schema are unchanged from 0.35.1. Existing room and commander data can be retained when installing this patch.
