# Horizon 0.31.1: Horizon Academy

## Guided faction training

- Adds Horizon Academy to the lobby with First Horizon fundamentals and a training page for all eleven playable factions.
- Adds a fixed three-stage scenario for every faction: Foundation, Signature Ability, and Mastery.
- Each exercise loads a prepared early, middle, or late-game position with suitable Technology, resources, units, and infrastructure.
- Exercises can be restarted, the guide can be hidden without locking the interface, and graduation opens unrestricted practice.
- Academy saves use a separate cloud slot and do not affect normal match statistics.

## Shattered Reach clarity

- Adds visible Arkship, Grand Ark, Worldship, Blockade, and Caravan Guard markers to the board.
- Adds distinct map and detail treatments for Arcologies, Enhanced Centers, and Factories.
- Adds legal Bombardment range previews and visible Siege Tender support status.
- Replaces generic automatic tracking text with exact compound progress for all twenty-five Shattered Reach Civilization Legacy objectives.

## Expansion access foundation

- Adds provider-neutral entitlement records for playtest, Steam, Apple, Google, and web purchase verification.
- Adds offline verification windows and safe defaults for existing Commander accounts.
- Adds host-enabled multiplayer content policy. If the host enables Shattered Reach, every seat in that room may select its factions.
- Shattered Reach access is granted to all 0.31.1 playtest accounts.

## Stability and validation

- Advances game saves to schema 20 and rooms to schema 8 with backward-compatible normalization.
- Adds deterministic Academy, entitlement, visual representation, objective progress, and balance validation coverage.
- Corrects the Salvo Orders preview so unsupported range-2 Bombardments are no longer offered.
