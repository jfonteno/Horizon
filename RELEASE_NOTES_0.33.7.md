# Horizon 0.33.7

## Shattered Reach access audit

- Added a prominent faction construction section to the Build menu for the Spires, Aegis, Wayfarers, Salvo, and Guilds.
- Kept faction-specific vessels and upgrades visible before unlock, with exact Technology requirements and other prerequisite messages.
- Added Spires Defense Grid and Arcology entries to Spires Construction. Arcology remains exclusive to Spires Metropolises at Resource IV.
- Added the Aegis Defense Grid, Blockade Tender, and Blockade Platform to Aegis Construction.
- Added a Blockade Tender map action that opens the correct Habitat in Build for immediate platform deployment.
- Added owned Blockade operations to Build with a direct route to the existing agreement-based sale flow in Diplomacy.
- Added all Wayfarer mobile Habitats, Gunnery Platforms, mobile Centers, and Caravan Guards to Wayfarer Construction. Mobile installations can target any owned deployed mobile Habitat.
- Added all Salvo artillery vessels and the Siege Tender to Salvo Construction. Bombardment remains available directly from artillery vessel selection.
- Added Guild Factory, Enhanced Center, and Factory output controls to Guild Construction.
- Added regression coverage that validates every expansion faction's construction quotes, resolved Aegis deployment, and player-facing action access.

## Compatibility

- Existing 0.33.x rooms and Commander profiles remain compatible.
- No account, room, or content schema migration is required.
