# Horizon 0.27.0: Unified Command Interface

## One board for every mode

Local games, First Horizon, Quick Start, spectator simulations, and network rooms now launch through the authoritative room service and use the same Command Board. Local pass-and-play changes the active private seat after each sealed submission instead of returning to the retired local interface.

## Previous Orders

Every resolved Turn records a bounded public replay containing unit paths and outcomes, changed Habitats and Centers, new vessels, Combat Unit changes, Technology advances, Gate contributions, Legacy changes, and public resolution events. The command briefing and Orders panel both open the replay map. Players can inspect any retained Turn without exposing private surveys, Hidden objectives, or unsealed drafts.

## Public information and training

Civilization cards now open a public dossier with resources, Labor, Habitats, Centers, expected production, Combat Units, Technology, Gate contributions, and Civilization Legacy progress. Horizon Academy provides a class for every core faction. First Horizon guidance runs as a nonblocking coach card and leaves every command surface available.

## Timers and private drafts

Room timers support one minute through 48 hours. Draft Orders synchronize privately to the authoritative room after editing. When a deadline expires, Horizon validates and seals the last saved draft for each unsubmitted civilization. Automatic Hold is used only when no valid draft exists. Turns still resolve immediately when everyone seals early.

## Interface and presentation

The main soundtrack now runs across the full menu and stops when an active board opens. Activity, connection, and draft messages are consolidated into board-owned surfaces instead of covering the Seal Orders control. Phones use a five-action command bar with a complete More directory. The active board uses new responsive tactical star-chart artwork distinct from the menu and lobby backgrounds.
