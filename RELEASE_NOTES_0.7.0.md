# Horizon 0.7.0: Exploration and Faction Completion

## Added

- Foundry Prospectors with construction, movement, and once-per-hex Prospect actions.
- Aurelian Envoys with foreign Habitat hosting and automatic hosted-trade Influence.
- Meridian Brokerage between two other civilizations, including once-per-Turn pair limits and automatic Currency income.
- Meridian Economic Salvage at Economy III.
- Farbound Forward Scanning from the Exploration vessel.
- Farbound Long-Range Surveyors and once-per-Turn board-wide private surveys.
- A private Farbound survey archive that never publicly reveals scanned tiles.
- Survey Exchange sales with buyer, price, and Civilization Legacy tracking.
- Surveyed Habitat settlement rebates and the first discounted Habitat Labor benefit each Era.
- Map markers for faction civilian vessels.
- Automatic faction-scoring checks for Prospectors, Envoy hosts, Brokerage, surveys, discounted Habitats, and information sales.
- Improved Anomaly resolution tracking, preserving the civilization that earned the first-reveal Research.

## Compatibility

Version 0.7.0 migrates previous saves to schema version 7. Existing diplomacy, fleets, Legacy claims, private objectives, map state, and scores remain intact.
