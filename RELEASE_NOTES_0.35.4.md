# Horizon 0.35.4 UI playtest patch

- The Technology Tree is a vertical, color-coded list of branches. Open a branch to see levels I–IV, then open a level to read its effects inline. This layout is shared by the main-menu archive and in-game Technology drawer on desktop and mobile.
- Each level explains the rule available to every civilization first. A separate section lists relevant faction unlocks with faction emblems, colors, and short descriptions.
- Prerequisites, current research costs, red shortages, and the Technology Order action remain available in the expanded level. Future levels remain explorable.

No game rules or saved-game format changed. Preserve existing room and commander data when updating.
