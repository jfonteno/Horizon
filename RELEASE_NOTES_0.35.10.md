# Horizon 0.35.10 playtest patch

- Selecting Move highlights every reachable destination for the selected Exploration vessel, Colony Ship, civilian vessel, or military task force. Clicking one highlighted hex drafts the move immediately, with a path that prefers to avoid known hostile hexes. There is no waypoint confirmation prompt.
- Exploration vessels can move into and reveal reachable unknown hexes even if they previously used their public scan allowance in the same Turn. Scanning remains limited by Exploration Technology. Movement range, portals, impassable sectors, and Turn readiness still apply.
- Faction standings use wider fixed-width cards and a horizontally scrollable strip on desktop and mobile. Resource icons and values stay on one line.

Includes all changes through 0.35.9. Existing room and commander data can be retained during the update.
