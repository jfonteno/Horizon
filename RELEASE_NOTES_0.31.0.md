# Horizon 0.31.0: Shattered Reach

Shattered Reach is now a playable expansion test package with five new civilizations: the Spires, Aegis, Wayfarers, Salvo, and Guilds.

## Included

- Five complete faction profiles with supplied emblem artwork, Academy entries, starting packages, and five automatic Legacy paths each.
- Spires urban discounts, scalable Defense Grids, and four-slot Arcologies.
- Aegis enhanced Home Guard, Blockade Tenders, independent Blockade Platforms, and explicit allied platform transfers.
- Wayfarer Arkships, Grand Arks, Worldships, Caravan Guards, Gunnery Platforms, atomic Migration Orders, and private Deep Recon.
- Salvo Bombard Frigates, Siege Cruisers, Siege Tenders, ammunition rules, target damage caps, and final-CU protection.
- Guild Enhanced Centers, permanent Labor tradeoffs, Precision Construction, configurable Factories, and high-output Legacy objectives.
- Expansion-aware bot planning, network Orders, save migration, turn logs, and construction previews.

## Compatibility

- Save schema 19 migrates earlier matches with empty expansion collections and metrics.
- Existing factions, maps, Colony Ships, content packs, and multiplayer rooms remain compatible.
- The Shattered Reach map remains part of the base map catalog. The expansion package adds factions and mechanics without removing existing map access.

## Playtest notes

- Guild Enhanced Center limits apply per Habitat so the six- and eight-Center Legacy objectives remain attainable.
- Gun for Hire uses a same-Turn Bombardment attribution ledger to recognize later third-party victories automatically.
- Costs and Combat Strength values marked for calibration in the design freeze remain playtest values.
