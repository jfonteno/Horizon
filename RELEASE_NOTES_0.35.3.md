# Horizon 0.35.3 UI playtest patch

- On mobile, the right-side menu launcher is a horizontal, scrollable row. Technology is visible near the start, and all menu tabs remain accessible. The main-menu Technology Tree can also be reached by scrolling the home menu.
- Gate and Legacy have moved from the left command dock into the right-side menu. A Resources tab replaces the old retractable map overlay and shows current reserves, Labor, Legacy Points, next production, and production sources.
- Gate progress comes first. The Add Tribute action follows it, with a resource-icon cost display and red shortages. The faction contribution list has faction emblems, faction tints, Era totals, and a highlighted contribution leader.
- Legacy places the current Hidden objective first. Universal and Civilization objectives are in separately colored columns on larger screens and stack on mobile. Hidden history is collapsible.

No game rules or saved-game format changed. Preserve existing room and commander data when updating.
