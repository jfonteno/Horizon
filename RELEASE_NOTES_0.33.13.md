# Horizon 0.33.13

## Unified Habitat Construction

- Selecting a controlled Habitat on the map now opens the full Build interface with that Habitat already selected.
- Opening Build from the command bar uses the same interface and asks the player to select a controlled Habitat.
- The incomplete contextual build inventory has been removed, so there is only one source of construction options.

## Complete Faction Access

The unified Build interface includes:

- Spires Defense Grids and Arcologies
- Aegis Defense Grids, Blockade Platforms, Blockade Deployment Vessels, and Blockade operations
- Wayfarer mobile Habitats, Mobile Centers, Caravan Guards, and Gunnery Platforms
- Salvo artillery vessels and Siege Tenders
- Guild Enhanced Centers, Factories, and Factory output controls
- Every standard Habitat, Center, vessel, recruitment, and infrastructure construction

## Interaction Consistency

- Build-location targeting opens the complete menu after a Habitat is selected.
- The Blockade Deployment Vessel's construction shortcut routes through the same Build interface.
- Contextual Habitat panels retain a direct link to the complete Build interface if reached from another action.

## Compatibility

- Existing rooms, saves, accounts, Orders, and construction state remain compatible.
- This update changes only how construction options are reached and displayed.
